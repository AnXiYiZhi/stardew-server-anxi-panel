# 快速上手

`Anxi Panel` 是围绕 [JunimoServer](https://stardew-valley-dedicated-server.github.io/server/) 构建的星露谷物语（Stardew Valley）专用服务器 Web 管理面板。

::: tip 联机设备支持范围
电脑端玩家可在游戏版本与 Mod 一致时加入同一服务器。iOS / Android 的多人模式仍是官方标注的实验功能，只支持通过 IP 加入，并更适合同一局域网；Apple Arcade 版本不支持。主机平台不支持与电脑或手机端通用跨平台联机。

开始邀请朋友前，建议先看 [官方移动端多人指南](https://www.stardewvalley.net/mobile-multiplayer-guide/) 和 [Stardew Valley Wiki 的联机限制](https://wiki.stardewvalley.net/Multiplayer)。

▶️ **[点此观看视频教程](https://www.bilibili.com/video/BV1GvMG6jE71/)**
:::

星露谷联机常卡在房主在线、跨平台加入、异地网络、端口转发、Steam 邀请、存档回档和 Mod 对齐上。这个项目的目的就是为了解决这些痛点。

## 四步跑起来

1. **[服务器选择](/guide/choose-server)**：确认系统要求，没有服务器的话可以先领阿里云免费试用。
2. **[部署安装](/guide/deploy)**：一条命令跑一键脚本，装好 Docker、拉镜像、启动面板。
3. **[首次进入面板](/guide/first-login)**：建管理员账号、安装游戏，再创建或导入存档并启动。
4. **邀请朋友**：服务器真正进入运行状态后，再复制邀请码或 IP 直连地址。
