# 首次进入面板

面板部署完成后，第一次打开会依次引导你完成创建管理员、安装游戏、建/传存档和局域网/IP 直连。Steam 邀请码是管理员按需启用的可选能力，不是首次安装的必经步骤。

## 1. 创建管理员账号

打开浏览器访问面板地址，首次会进入管理员初始化页，设置用户名和**强密码**。

## 2. 安装游戏

登录后进入“安装”页，填写 Steam 账号、Steam 密码和 VNC 密码，点击开始安装。首次安装默认走 SteamCMD：依次准备 Stardew Valley（App 413150）、Steamworks SDK（App 1007）、SMAPI 和 Junimo/Control 运行文件，并完成最终校验。如果 Steam 需要二次验证，页面会提示用手机 App 批准或输入 Guard 验证码。

默认安装不会拉取、启动或探测 SteamAuth；Auth 缺失和 Auth 授权失败都不会影响游戏安装结果。

## 3. 启动服务器

安装完成后回到"总览"或"服务器"页，点击启动服务器。

## 4. 新建或上传存档

首次启动如果没有存档，会引导你选择：

- **新建存档**：在面板里填农场名、玩家名、地图类型等设置，直接生成新农场。
- **上传存档**：上传自己电脑上的 Stardew 存档 ZIP，面板会先预览游戏时间、地图、玩家名再确认导入。（测试阶段）

## 5. 通过局域网 / IP 直连邀请好友

服务器启动后，在“总览”或“服务器”页找到“局域网直连”，复制显示的地址给朋友。是否能加入仍受 Stardew Valley 客户端平台、版本和网络条件限制；移动端多人模式属于游戏自身的实验功能，Apple Arcade 的 Stardew Valley+ 不支持，细节见 [Stardew Valley 官方移动端多人指南](https://www.stardewvalley.net/mobile-multiplayer-guide/)。Panel 的局域网/IP 直连本身不需要 Steam 邀请码。

## 6. 按需启用 Steam 邀请码（可选）

确实需要 Steam 好友邀请码时，由管理员先停止服务器，再到“安装”页点击“启用 Steam 邀请码（需要再次登录授权）”。Panel 此时才按需准备 Auth 镜像，并通过一次性授权容器引导完成二维码、手机批准或 Guard 验证；session 保存后，这个登录容器会停止。之后启动服务器，邀请码卡会等待 Auth sidecar 生成邀请码。

授权失败只影响 Steam 邀请码状态，不会把已经安装好的游戏改成安装失败；局域网/IP 直连仍然可用。SteamCMD 授权缓存和 SteamAuth session 会分别保存并优先复用。管理员使用“修改 Steam 账号密码”只会更新两条流程共用的备用凭据，不会主动清除仍有效的缓存或 session，也不会立即启动重新授权。
