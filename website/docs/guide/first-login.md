# 首次进入面板

面板部署完成后，第一次打开按“创建管理员 → 安装游戏 → 创建或导入存档并启动 → 邀请朋友”的顺序操作。没有可用存档时，服务器不会直接启动。

## 1. 创建管理员账号

打开浏览器访问面板地址，首次会进入管理员初始化页，设置用户名和**强密码**。

## 2. 安装游戏

登录后进入"安装"页，填写 Steam 账号、Steam 密码和 VNC 密码，点击开始安装。安装会自动拉取 JunimoServer 相关镜像并运行 Steam 登录；如果 Steam 需要二次验证，页面会提示手机 App 批准或输入验证码。

## 3. 新建或上传存档并启动

安装完成后，面板会进入“需要选择存档”状态。先去“存档”页选择一种方式：

- **新建存档**：填写农场名、玩家名、地图类型等设置，确认后点击“创建并启动”。
- **上传存档**：上传自己电脑上的 Stardew 存档 ZIP，先预览游戏时间、地图和玩家名，确认无误后点击“导入并启动”。

这两个流程都会先建立或接管存档，再启动服务器；不要在没有存档时反复点击“启动”。

## 4. 邀请好友加入

服务器显示“运行中”后，去“玩家”页复制邀请码，或把“局域网邀请”里的 IP 直连地址发给朋友。

- 电脑端需要保持游戏版本一致；使用 Mod 时还要按面板生成的同步包对齐客户端 Mod。
- iOS / Android 只能使用官方实验性的 IP 加入方式，建议优先在同一局域网测试；Apple Arcade 版本不支持。
- Switch 等主机平台不能作为电脑 / 手机专服的通用跨平台客户端。

设备限制以 [官方移动端多人指南](https://www.stardewvalley.net/mobile-multiplayer-guide/) 和 [Stardew Valley Wiki](https://wiki.stardewvalley.net/Multiplayer) 为准。
