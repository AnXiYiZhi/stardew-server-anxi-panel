# 使用面板

这里按你要完成的事情组织，而不是要求你先记住面板里每个页面的名字。还没部署或第一次打开面板，请先走 [开始开服](/guide/getting-started)。

## 第一次进入面板

1. [界面总览](/handbook/ui)：认识桌面与手机端导航、状态提示和右侧信息栏。
2. [安装游戏](/handbook/install)：完成 Steam 登录、Steam Guard、游戏与运行组件安装。
3. [存档管理](/handbook/saves)：创建新农场，或预览并导入已有存档。
4. [服务器控制](/handbook/server-control)：有可用存档后再启动，获取邀请码或 IP 直连地址。

## 管理农场内容

- [存档管理](/handbook/saves)：切换、导出、删除存档，配置自动回档并恢复备份。
- [Mod 管理](/handbook/mods)：搜索、安装、启停 Mod，处理依赖并导出玩家同步包。
- [玩家管理](/handbook/players)：查看名册与活动，踢出、临时封禁或删除离线角色。

## 管理面板与权限

- [账号与权限](/handbook/accounts)：管理员初始化、面板用户、角色和审计边界。
- [面板设置](/handbook/settings)：端口、用户、安全状态与 Docker Socket 权限说明。
- [任务与日志](/handbook/jobs-logs)：查看安装、导入、更新等后台任务的实时进度。

## 出问题时

先按 [常见问题](/faq/) 里的现象查找；仍未解决时打开 [诊断与支持包](/handbook/diagnostics)，导出已经脱敏的诊断信息再反馈。

::: tip 完整教程与速查表的分工
本手册是每个功能的权威完整说明；[日常维护](/maintain/update) 只保留高频操作的短步骤，并链接回这里。以后同一规则发生变化时，应先更新对应手册页，避免两套说法逐渐不一致。
:::
