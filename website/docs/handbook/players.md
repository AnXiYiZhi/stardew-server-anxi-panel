# 玩家管理

“玩家”页展示服务器名册和最近活动，支持踢出在线玩家、临时封禁玩家和删除离线玩家角色。白名单与权限设置仍是待接入能力。

## 玩家名册

表格展示在线和离线玩家：

- **状态点**：在线（绿点）、等待加入中（黄点，包含正在连接/等待/加入几种子状态）、离线（灰点）、未知（灰点，状态无法读取）。
- **在线时长/最近上线**：优先显示短格式时间点，比如"今天 14:20"、"昨天 09:10"、"3天前 20:00"；拿不到具体时间点才回退显示时长文案。
- **收入列**：玩家个人收入、农场总收入（服务器运行中实时读取）。
- 离线玩家如果存档文件里能找到但当前不在线名单，也会被列出并标注为离线，方便你确认这个存档一共有哪些玩家角色。

## 查看玩家上报的 Mod

存在联机 ID 的玩家会显示“查看上报 Mod”；检测到官方 CJB Cheats Menu 或 Item Spawner 时，入口会直接提示“检测到 CJB 作弊”。桌面端会进入独立详情页，手机端会在玩家页内打开共用详情并提供返回按钮。

详情按“玩家额外安装、玩家缺少 Mod、版本不同、匹配”展示。玩家缺少只统计服务器已启用且要求客户端同步的 Mod；服务器专用 Mod 不会进入缺少警告。SMAPI、Junimo Controller 和 Anxi Panel Control 属于运行组件，不参与普通 Mod 比较。

::: warning 上报清单不是可信审计
Mod 清单来自客户端通过兼容 SMAPI 连接主动上报，只用于管理员人工参考。CJB 提示只按官方 UniqueID 识别，修改 manifest ID 可能绕过；面板不会根据结果自动踢出、封禁或阻止玩家加入。
:::

::: info 未上报不等于没有 Mod
页面显示“该客户端未上报 Mod 清单”时，常见于原版 PC、手机、平板或不兼容的 SMAPI。这不会显示为 0 个 Mod、完全一致或安全，也不会影响玩家正常加入。
:::

## 玩家活动 / 最近事件

分页展示的事件流，记录玩家加入、离开等动作，每页 2 条，用上一页/下一页翻页。

## 管理操作

右侧"管理操作"卡列出四项：

| 操作 | 当前状态 |
| --- | --- |
| 踢出玩家 | **已接入**：可在玩家表格行内点踢出图标，或在下方选择在线玩家后点"踢出"，二次确认后提交 |
| 封禁玩家 | **已接入**：可从玩家行内封禁非主机角色；在线或离线角色都可以作为目标 |
| 白名单管理 | 按钮已展示，待接入 |
| 权限设置 | 按钮已展示，待接入 |

::: tip 踢出玩家怎么用
只有当前**在线**且**不是主机**的玩家才能被踢出。点击踢出后会弹出二次确认框，确认后指令会提交给服务器内置的控制模组，通常几秒内生效，玩家会被断开连接（仍可以重新加入）。主机玩家出于安全考虑无法被踢出。
:::

::: warning 封禁在容器重启后会丢失
封禁会立即断开目标玩家并阻止其再次加入，但当前记录保存在游戏服务器运行时内存中。服务器容器重启后，封禁记录会丢失，需要管理员重新操作。主机角色不能被封禁。
:::

::: tip 删除离线角色怎么用
如果某个玩家长期不来、占着角色位置，管理员可以在服务器**运行中**对该角色执行删除。操作入口在玩家名册的离线角色行，只对当前活动存档里已认领、非主机、且处于离线状态的角色生效。删除前面板会自动备份整档，删除后该角色和小屋将从存档中永久移除，玩家重新上线时会被自动中止连接。详见 [存档管理 - 删除离线玩家角色](/handbook/saves#删除离线玩家角色)。
:::

::: warning 目前还做不到的
白名单管理和权限设置仍是禁用占位。当前封禁也不是持久封禁；如果需要长期限制加入，仍应配合[服务器加入密码](/handbook/server-control#服务器密码设置)，并在服务器容器重启后重新确认封禁状态。
:::
