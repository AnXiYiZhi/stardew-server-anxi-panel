# 存档与备份

## 新建 / 上传存档

首次启动服务器如果没有存档，会引导你选择：

- **新建存档**：在面板里填农场名、玩家名、地图类型等设置，直接生成新农场。
- **上传存档**：上传自己电脑上的 Stardew 存档 ZIP，面板会先预览游戏时间、地图、玩家名再确认导入。

## 自动备份策略

“存档”页左下角“自动备份策略”可以配置：

- **睡觉存档后创建回档点**：游戏完成保存并写盘后，自动创建该游戏日的 ZIP 回档点。
- **保留最近 N 个游戏日**：默认 5 个，可设置为 1–14 个。同一游戏日重复保存会覆盖同一天，跨季节和年份按游戏日期连续排序。

v0.4.4 起，Panel 在后台及时消费保存事件，不需要打开备份列表才能生成回档点。旧版本已经漏掉的历史游戏日无法用当前存档反向补齐；升级后从下一次睡觉保存开始连续生成。

自动清理只处理“游戏日回档”，不会删除手动备份或删除、回档、人物删除、导入、运行组件升级前创建的保护备份。列表支持“回档到此日”和“彻底删除”；重要节点（例如批量安装或删除 Mod 前）仍建议额外创建一次手动备份。

## 计划重启（定时维护窗口）

"服务器"页的"计划重启"可以设置每天固定的关闭时间和开启时间：

- 可设置关闭前提前几分钟通过游戏内聊天广播提醒在线玩家。
- 可选"关闭前自动备份当前存档"，关闭前先打包一份存档备份再停止服务器。
- 可选"有玩家在线时跳过本次关闭"，避免打断正在游玩的玩家。
- 到设定的开启时间会自动重新启动服务器；面板重启或长时间离线后，只在开启时间之后 5 分钟宽限窗口内补跑一次，不会补跑很久以前错过的时间点。
