## 部署与访问

### 面板打不开或容器起不来

<details open>
<summary>查看检查顺序</summary>

1. 确认宿主机端口 `8090` 没有被其他程序占用；需要时改用其它端口，例如手动部署时用 `-p 9090:8090`。
2. 确认启动配置挂载了 Docker Socket：`-v /var/run/docker.sock:/var/run/docker.sock`。没有这个挂载，面板无法创建和控制游戏容器。
3. NAS 图形界面如果不允许挂载 `/var/run/docker.sock`，当前架构无法正常工作，需要换支持该挂载的部署方式。
4. 容器已经运行但网页打不开时，再检查云安全组或 NAS 防火墙是否放行 `TCP 8090`。

</details>

### 安装镜像拉取失败

<details>
<summary>查看网络与镜像源处理方法</summary>

- 面板会依次尝试 JunimoServer 与 steam-auth 的多个镜像候选源，日志里的 `(1/4)` 一类文字表示正在安全切换候选，并不等于整个任务已经失败。
- 所有候选都失败通常说明服务器 DNS 或公网连接异常。面板有 DNS 自愈，但服务器完全无法访问公网 DNS 53 端口时仍需检查防火墙或联系服务商。
- 家用 NAS 的路由器 DNS 不稳定，也可能让 Nexus、Docker Hub 版本检查间歇失败。

</details>

## 安装游戏

### Steam 登录或 Steam Guard 一直卡住

<details>
<summary>查看登录检查顺序</summary>

- 安装页优先使用账号密码登录；Steam 要求二次验证时，按页面提示在手机 App 批准或输入验证码。
- 长时间没有进展时，先看任务日志是否仍在连接重试。
- 反复失败可以停止服务器后回到“安装”页重新发起登录，不会清空已经下载的游戏文件。

</details>

### 安装游戏卡住

<details>
<summary>游戏和 SDK 已完成，但 SMAPI 安装失败</summary>

1. 在“诊断”页确认 Panel 为 `v0.4.5` 或更高版本。
2. 回到“安装”页点击“重新安装 / 修复”。新版本会依次尝试受审加速地址，最后回退到 GitHub 官方，并支持分块续传；不需要重新认证 Steam。
3. 某个候选失败后继续下一候选是正常回退。全部候选都失败时，检查 DNS、HTTPS 出站网络、磁盘空间和系统时间。
4. 不要在 `.env` 临时加入陌生下载代理。Panel 会拒绝未受审 URL，并校验文件大小、SHA-256 和 ZIP 结构。

完整机制见 [安装游戏：SMAPI 加速与断点续传](/handbook/install#国内网络-smapi-加速与断点续传)。

</details>

## 邀请与联机

### 邀请码一直“获取中…”或显示 n/a

<details>
<summary>查看替代加入方式</summary>

- 邀请码依赖 Steam SDR / Galaxy P2P 中继，网络不稳定时可能卡住，不代表服务器没有成功启动。
- 电脑端可以优先尝试“玩家”页的 IP 直连；确认服务器“运行中”并开放 `UDP 24642`。
- iOS / Android 的多人模式是官方实验功能，只支持 IP 加入，并更适合同一局域网；Apple Arcade 版本不支持。

</details>

### 朋友无法加入

<details>
<summary>查看端口与版本检查顺序</summary>

1. 最常见原因是只开放了 TCP：必须放行 `UDP 24642` 和 `UDP 27015`。
2. 云服务器检查安全组；NAS 检查路由器是否把两个 UDP 端口转发到 NAS 的局域网 IP。
3. 确认面板显示“运行中”，而不是安装中、启动中或“需要选择存档”。
4. 所有电脑端玩家保持相同游戏版本；使用 Mod 时按面板导出的同步包对齐客户端 Mod。

完整说明见 [端口与安全组](/deploy/ports)。

</details>

## 存档

### 当前激活存档显示“未知”

<details>
<summary>查看是否需要处理</summary>

- 新建存档还没有完成第一次游戏内过夜存档时，面板暂时读不到农场主与日期，属于正常中间状态。
- 远超一次正常存档耗时后仍显示“未知”，但玩家可以正常进入，说明游戏本身可用；更新 Panel 到最新版本后再观察存档指针是否自动修正。

</details>

### 存档无法启动

<details>
<summary>查看错误提示对应处理</summary>

- `save_required`：游戏已经安装，但还没有可用存档。去“存档”页新建或上传，不要继续反复点击启动。
- VNC 端口不可用：宿主机默认 `5800` 被占用，在设置里更换端口或停止占用该端口的程序。
- 导入失败或预览解析失败：先保留原 ZIP，不要反复覆盖，去“任务与日志”查看具体任务错误。

</details>

## Mod

### Mod 搜索或安装失败

<details>
<summary>查看 Nexus 与依赖检查</summary>

- Nexus 数字 ID 精确查询需要先配置管理员 API Key；普通关键词搜索不需要。
- 使用浏览器扩展一键安装时，确认扩展版本与面板提示一致。
- 批量安装中重复的 Mod 会显示“已安装，跳过重复导入”，不算失败。
- 上传、安装、删除和启停 Mod 前先停止服务器；停服改完后下一次正常启动就会加载。

更多操作见 [Mod 管理](/handbook/mods)。

</details>

## 面板操作与更新

### 复制按钮点击没有反应

<details>
<summary>查看 HTTP 访问下的兼容处理</summary>

早期版本通过 `http://IP:端口` 访问时，浏览器复制 API 可能不可用。更新 Panel 到最新版本后，复制按钮会自动使用兼容方案。

</details>

### 更新后版本没有变化

<details>
<summary>查看更新命令</summary>

如果普通更新仍使用旧缓存，强制重新拉取并重建面板容器：

```bash
cd ~ && bash run.sh force-update
```

如果 `run.sh` 本身也需要更新，先更新脚本，再更新面板：

```bash
cd ~ && bash run.sh update-script
cd ~ && bash run.sh update
```

</details>

## 仍未解决

在“诊断”页导出诊断包。它包含版本、健康检查、任务日志和 Compose 状态，并会自动脱敏密码与 Token。反馈问题时同时说明“做到哪一步、看到什么现象、最近一次任务时间”，比只发一张报错截图更容易定位。
