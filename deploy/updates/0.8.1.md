v0.8.1 修复游戏运行栈升级被独立更新的 Steam SDK 阻塞的问题。游戏 build、depot 和内容哈希继续固定核验；SDK 使用实际完整安装的 Linux depot，独立核验运行文件并保留实际 manifest 身份。

本版分别显示预检执行中、预检失败和真正过期。过期的准备可重新检查范围；运行中自动存档短暂替换文件时，预检会有界等待稳定读取，取消、权限、精确范围与回滚保护继续生效。

修复首次安装时账号或密码错误后无法继续重试的问题。重新填写凭据会保留原下载进度并继续使用本次安装的游戏卷。

从 v0.7.3 更新时，旧客户端会先发现并更新面板至 v0.8.1。页面刷新后，再在 v0.8.1 更新中心检查和确认需要迁移的游戏组。旧客户端只内置了 v0.8.0 的提前范围确认能力，不能替后续版本预先确认未知的游戏变更。后续正式版本采用相同发现与确认顺序，不固定停留在 v0.8.0 或 v0.8.1。

请安排维护时间，并保留独立备份。游戏运行栈迁移会断开在线玩家，按组保存、停服、备份和验收，完成后恢复原来运行的世界；原来停止的世界保持停止。第三方 Mod 请先确认兼容性。已有未完成事务应从原操作的恢复入口继续。

为保护更早客户端，GitHub 网页的 latest 入口保留 v0.7.3；v0.7.3 及以后通过正式 Release 列表选择适用的最高稳定版本，包括 v0.8.1 和后续补丁。发布验收中的上一正式版按列表选择，本次为 v0.8.0；v0.7.3 作为受影响的更早升级来源单独验证。
