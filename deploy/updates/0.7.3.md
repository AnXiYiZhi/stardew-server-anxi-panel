v0.7.3 是游戏实例大更新的准备版。v0.7.2 及更早版本先通过 Web 更新到本版；完成后，更新中心才会提供满足前置条件的后续正式版本。

本版保留 Junimo .125 与 Auth 1.5.0-anxi.2 的组合，按兼容规则维护 Control 补丁，不会迁移到 .140。游戏库、世界列表和实例入口共用更新中心，提示和升级范围由管理员确认。

Panel 重建期间网页会暂时断开并自动重连。升级前创建 SQLite 一致性备份；新 Panel 健康检查失败时恢复旧版本和对应数据库备份。建议另外导出存档与配置备份。

GitHub latest Release 固定 v0.7.3，供旧版完成准备；v0.7.3 及以后从正式 Release 列表选择可达版本。Docker latest 是独立入口，按正式镜像发布流程更新。v0.8.0 正式发布后，可从更新中心继续执行实例大更新。
